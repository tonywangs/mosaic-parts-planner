# Synthetic landscape

`source.png` is an original, deterministic 24×16 synthetic landscape created by
`mosaic-parts example`. `inventory.json` contains illustrative approximations,
including only 70 dark-teal tiles. `preview.png` shows the constrained result.
These RGBs do not refer to verified commercial tile colors.

Regenerate the inputs and full plan in a new directory:

```sh
.venv/bin/mosaic-parts example --output example-output/input
.venv/bin/mosaic-parts convert example-output/input/source.png \
  --inventory example-output/input/inventory.json --width 24 --height 16 \
  --output example-output/plan
```

The source is generated by integer arithmetic without a random seed or external
assets. The preview is nearest-neighbor enlarged to show each tile clearly.
